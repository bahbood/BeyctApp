پرتال جامع شهری 
شامل : خبرنامه - بازارچه  - خدمات

یوزر از طریق پیامک و ثبت شماره موبایل تایید و امکان استفاده از امکانات سایت را خواهد داشت
در هنگام ثبت نام و بعد از تایید اولیه هیچ یک از امکانات سایت برای یورز فعال نخواهد بود
هر یوزر تایید شده میتواند یک فروشگاه - یک آزانس خبری و چند بخش ارائه خدمات  داشته باشد
